# Hangar 8

Sitio institucional de Hangar 8, taller integral de chapa y pintura en Ituzaingó.

```bash
npm install
npm run dev      # desarrollo
npm run build    # sitio estático en dist/
npm run check    # build + accesibilidad + responsive + capturas en .checks/
```

- Contenido: `src/data/site.ts`
- Reglas del proyecto: `CLAUDE.md`
- Qué falta: `PROGRESS.md`
